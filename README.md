# 🎬 블로그 → 쇼츠 자동 제작 파이프라인

블로그 글을 크롤링해 쇼츠 대본과 음성을 생성하고, 이미지·자막의 타이밍을 맞춰 최종 MP4 영상을 제작하는 프로젝트입니다.

## 개발 진행 현황

| 단계 | 작업 | 상태 | 구현 파일 |
| --- | --- | --- | --- |
| 1 | 블로그 글 크롤링 | ✅ 완료 | `crawler.py` |
| 2 | 본문 섹션 분리 및 이미지 추출 | ✅ 완료 | `crawler.py` |
| 3 | AI 쇼츠 대본 생성 | ✅ 완료 | `script_generator.py` |
| 4 | 장면별 이미지 자동 배분 | ✅ 완료 | `image_allocator.py` |
| 5 | TTS 음성 생성 | ✅ 완료 | `tts_generator.py` |
| 6 | 실제 음성 길이 측정 | ✅ 완료 | `tts_generator.py` |
| 7 | 이미지 전환 시간 계산 | ✅ 완료 | `edit_planner.py` |
| 8 | **음성과 자막 싱크 맞추기** | ⏳ 예정 | `subtitle_generator.py` |
| 9 | **자막을 영상 편집 계획에 통합** | ⏳ 예정 | `edit_planner.py` 수정 |
| 10 | **MP4 최종 렌더링** | ⏳ 예정 | 렌더링 기능 구현 |

## 전체 처리 흐름

```text
블로그 URL 입력
    ↓
블로그 글 크롤링 및 이미지 추출       ✅
    ↓
AI 쇼츠 대본 생성                  ✅
    ↓
장면별 이미지 자동 배분             ✅
    ↓
TTS 음성 생성 및 길이 측정          ✅
    ↓
이미지 전환 시간 계산              ✅
    ↓
음성과 자막 싱크 맞추기            ⏳
    ↓
자막을 최종 영상 편집 계획에 통합    ⏳
    ↓
MP4 렌더링                       ⏳
    ↓
쇼츠 영상 완성
```

## 다음 작업

1. **자막 타이밍 생성:** 생성된 MP3와 나레이션을 바탕으로 자막 시작·종료 시간을 계산합니다.
2. **편집 계획 통합:** 기존 `edit_planner.py`에 자막 타이밍 정보를 결합합니다.
3. **MP4 렌더링:** 이미지, 음성, 자막을 합쳐 세로형 쇼츠 영상을 출력합니다.

## 최종 목표

사용자가 블로그 URL을 입력하고 **영상 생성하기** 버튼을 누르면, 크롤링부터 대본·음성·편집·렌더링까지 자동으로 실행되도록 각 단계를 연결합니다.
